# ぴょんぴょんノート（kaede/）

妹（小2、バンコクのインター校、2027年8月に小3で帰国）のための学習アプリ。兄の「学習ノート」（リポジトリ直下）とは別のアプリで、このフォルダの中だけで完結する。
父親（依頼者）は非エンジニア。報告は日本語で、短く、結論から。

- 公開URL: https://ryonagamatsu.github.io/gakushu-note/kaede/ （きょうの宿題を直接開くのは末尾に `#today`）
- 答え・手書き・採点: 非公開の `RyoNagamatsu/gakushu-data` の `kaede/data/`, `kaede/grades/`（兄と同じ鍵で送る）
- 学習計画・実力テストの結果・進み具合は、Claude のプロジェクト「楓の勉強」の文書にある（公開リポジトリには書かない）

## ファイル
- `index.html` … アプリ全体。変更したら `./kaede/deploy.sh "説明"` で反映（BUILD と `kaede/version.json` を更新して push）
- `weeks/index.json`, `weeks/<月曜の日付>.json` … 毎週の宿題と土曜テスト
- 書き順データは直下の `../kv/` を共用する。アイコンは白いうさぎ

## 週ファイルの形
兄のアプリと同じ基本形（`id`, `n`, `label`, `days[]`, `test`、ITEM は kanji / fill / choice / ink / long / sub）。ちがう点:
- `wd` は「げつ・か・すい・もく・きん」（画面では「げつようび」になる）。`label` は「だい1しゅう（10/12〜10/17）」
- 1日20分（`min:20`）: かん字2字 → さんすう10問前後 → ことば3問。土曜テストも20分で、月〜金の内容だけから出す（配点は自由。合計は自動計算）
- 問題文はひらがな中心の分かち書き。習っていない漢字は使わない。ふりがな機能と `why`、こたえあわせ画面、漢字の自動判定は**ない**（やり方は section の `note` に「れい」をつけて書く）
- えいごは宿題に入れない（英検4級満点レベル）
- 計算の答えは必ずプログラムで検算する。漢字の画数は `../kv/` の画数と合わせる

## アプリのしくみ
- 宿題やテストを1つ出すと、白いうさぎ「ぴょんぴょん」がにんじんを1本食べる。5日とも当日に出した週は＋2本。0/3/7/15/30本で育つ（`STAGES`）
- 宿題は日付が来ると開く（先取りはできない）。出すと赤字で答えが出る
- 見た目はピンクのかわいいデザイン（保護者OK済み）。サッカー・バレーボール・ワールドカップの題材は使わない
- 端末内の保存キーは `gk2.*`（兄のアプリは `gk1.*`。混ぜない）
